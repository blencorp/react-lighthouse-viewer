# Security policy

## Supported versions

Only the latest version gets security fixes.

## Report a vulnerability

Do not open a public issue. Report it privately with
[GitHub private vulnerability reporting](https://github.com/blencorp/react-lighthouse-viewer/security/advisories/new).
We reply within five working days.

Vulnerabilities in the Lighthouse report renderer itself belong to the
[Lighthouse project](https://github.com/GoogleChrome/lighthouse/security/policy).
